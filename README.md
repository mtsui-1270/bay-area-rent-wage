# Bay Area Rent vs. Wage Analysis

## Overview
This project analyzes the growing gap between rents and wages in the San Francisco Bay Area using real data from Zillow and the Bureau of Labor Statistics (BLS).

## Data Sources
- **Zillow Observed Rent Index (ZORI)** — monthly rent trends by metro area
- **BLS Occupational Employment and Wage Statistics (2024)** — median wages by occupation

## Key Findings
- Bay Area rents have increased significantly since 2015, with a dip during COVID-19
- Low-wage workers in food prep and retail earn far below the average monthly rent
- Only higher-wage occupations like software developers and nurses earn comfortably above rent

## Tools Used
- R (tidyverse, ggplot2, readxl, scales)
